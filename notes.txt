Stack
-----
- Static site in public/ (HTML, CSS, dependency-free SVG charts in app.js).
- Server-side / scheduled fetch: scripts/fetch-market.mjs (Node 20, no npm
  runtime dependencies) writes public/data/market.json.
- Hosting: GitHub Pages over HTTPS, deployed by .github/workflows/refresh.yml.
- Refresh: hourly cron at minute 7, plus workflow_dispatch and push to main.
- License: MIT (LICENSE).
- Local one-command: npm start
- Deploy one-command: documented in README.md (create empty public repo, push, set Pages source to GitHub Actions).

How we refresh
--------------
GitHub Actions runs node scripts/fetch-market.mjs, deploys the public/
folder to GitHub Pages, and on schedule / manual runs commits
public/data/market.json (message includes [skip ci] so the commit does
not loop the workflow). The browser never fetches api.taskmarket.dev
(no CORS).

Original views (beyond the required charts)
-------------------------------------------
- Open-task swarm: tile grid in the spirit of the Taskmarket mark; heat is
  submission count.
- Posted versus paid time series, plus expired/cancelled with zero awards
  counted from the task lists ("tasks that died").
- Poster concentration: share of tasks in 7 and 30 days made by the top
  three requesters, names only when requesterDisplayName is present.

API observation recorded in the snapshot
----------------------------------------
breakdowns, platform-time-series, and activity-heatmap returned identical
payloads for chainId 4217 and 8453. The site labels those views
platform-wide. paidWorkers and activeWallets differ by chain.
