Stack
-----
- scripts/fetch-market.mjs — Node 20 fetch, no npm runtime dependencies.
  Writes public/data/market.json. Never called from the browser.
- public/ — static HTML, CSS, and dependency-free SVG charts (app.js).
  Brand fonts and lockup from the public Taskmarket brand kit.
  Share image: public/img/og-1200x630.png
- Hosting: GitHub Pages over HTTPS, deployed by
  .github/workflows/refresh.yml
- No wallet libraries. No analytics or tracking.

How and how often it refreshes
------------------------------
GitHub Actions workflow "Refresh market and deploy Pages"
(.github/workflows/refresh.yml), state: active.

- Hourly cron: 7 * * * * (minute 7 of every hour, UTC)
- Also on workflow_dispatch and on push to main
- Each run: node scripts/fetch-market.mjs, then deploy the public/
  folder to GitHub Pages. On schedule or manual dispatch it also
  commits public/data/market.json (message includes [skip ci]) so
  the snapshot stays inspectable in git.
- The browser only loads data/market.json from this site. It never
  calls api.taskmarket.dev (the API does not allow CORS).
- The page shows a visible “data as of” timestamp in Eastern Time.
- Intended to stay up at least 30 days after payout with no paid
  hosting, as long as the repo stays public and Actions stay enabled.

Endpoints used
--------------
https://api.taskmarket.dev/api/market/stats?chainId=4217
https://api.taskmarket.dev/api/market/stats?chainId=8453
https://api.taskmarket.dev/api/stats/breakdowns?chainId=4217
https://api.taskmarket.dev/api/stats/breakdowns?chainId=8453
https://api.taskmarket.dev/api/stats/platform-time-series?chainId={4217,8453}&range={7d,30d,90d,all}&bucket={day,week}
https://api.taskmarket.dev/api/stats/activity-heatmap?chainId={4217,8453}&range={7d,30d,90d,all}&dimension={mode,hourOfWeek}
https://api.taskmarket.dev/api/stats/activity-feed?chainId={4217,8453}&limit=50
https://api.taskmarket.dev/api/tasks?chainId={4217,8453}&status={open,completed,expired,cancelled,claimed,worker_selected,pending_approval}&sort=newest&limit=100
  (paginated with cursor, up to 20 pages per status)

The methods panel on the site lists the exact URLs from the snapshot
and explains two important facts:

- On the snapshots taken so far, /api/stats/breakdowns,
  /api/stats/platform-time-series and /api/stats/activity-heatmap
  returned the same payload for chainId 4217 and 8453. Those views
  are labeled platform-wide. /api/market/stats differs by chain on
  paidWorkers and activeWallets.
- Distinct posters per week, the open-task swarm, poster
  concentration, and expired-or-cancelled tasks with zero awards
  are computed from each chain’s paginated /api/tasks list. A poster
  name is shown only when the API provides requesterDisplayName.
  Reward amounts are 6-decimal integers, divided by 1,000,000.

Deploy command
--------------
Local (Node 20+ and Python 3):

  npm start

That fetches a fresh snapshot and serves public/ at
http://127.0.0.1:8080

GitHub Pages (after this public repo exists):

  git clone https://github.com/dirtymullet/taskmarket-market.git
  cd taskmarket-market
  # Settings → Pages → Source: GitHub Actions (already set here)
  git push

The workflow deploys public/ and the hourly schedule keeps it current.
More detail is in README.md.

Original views
--------------
- Open-task swarm: tile grid in the spirit of the Taskmarket mark;
  heat is submission count.
- Posted versus paid time series, plus expired/cancelled with zero
  awards counted from the task lists.
- Poster concentration: share of tasks in 7 and 30 days made by the
  top three requesters, with names only when requesterDisplayName
  is present.
